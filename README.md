# Dimension.ai - Precision Measurement Tool

A browser-based calibration and layout tool designed for pixel-perfect screen measurements. It allows users to map their screen to a physical scale, making it easy to measure layouts, margins, and assets in inches or centimeters.

### Key Features
* **Edge Rulers:** 4-side full-bleed scales with tracking capabilities.
* **Floating Ruler:** A draggable, rotatable, and resizable virtual scale for measuring diagonal elements.
* **2-Point Measure:** Crosshairs and measurement bubbles to calculate spans and sub-pixel coordinates.
* **Screen Calibration:** Calibrates browser canvas to physical scale (PPI detection).

### Built With
* **Framework:** Astro, Node.js
* **Development Environment:** Antigravity IDE
